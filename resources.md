# Learning Resources

Every resource used in this roadmap with direct links and notes on what each one actually covers.

**Disclosure:** The general Scrimba link is a referral/affiliate link. The specific course path links are direct. Everything listed here is included because it's genuinely useful.

## Backend and Full-Stack

### Scrimba Backend Developer Path
**Link:** [scrimba.com/the-backend-developer-path-c0tbi0l98f](https://scrimba.com/the-backend-developer-path-c0tbi0l98f)
**Scrimba general (referral):** [scrimba.com](https://scrimba.com/?via=u43d5376)

Covers JavaScript for the backend, Node.js, REST APIs with Express, SQL and MongoDB, auth, and full-stack project building. The interactive format means you write code inside the lessons instead of a separate editor — good for beginners who need that immediate feedback loop.

Free tier available, some content needs a subscription.

Good for beginners and frontend devs who haven't done backend work before.

## AI Engineering

### Scrimba AI Engineer Path
**Link:** [scrimba.com/the-ai-engineer-path-c02v](https://scrimba.com/the-ai-engineer-path-c02v)
**Scrimba general (referral):** [scrimba.com](https://scrimba.com/?via=u43d5376)

Covers using LLM APIs in real apps, prompt engineering, RAG pipelines, embeddings, vector databases, agents, and building production AI features. Focuses on practical application over theory.

Free tier available, some content needs a subscription.

Good for developers who already know backend basics and want to start building with AI.

## Machine Learning

### DeepLearning.AI Machine Learning Specialization
**Link:** [learn.deeplearning.ai/specializations/machine-learning](https://learn.deeplearning.ai/specializations/machine-learning)

Supervised and unsupervised learning, neural network foundations, practical ML advice, recommender systems, and a solid intro to reinforcement learning. Taught by Andrew Ng. Video lectures, quizzes, and Python programming assignments using NumPy, scikit-learn, and TensorFlow.

Audit for free on Coursera (no certificate). Certificate requires a subscription.

Good for anyone who wants to actually understand how machine learning works, not just call APIs.

## LLM Internals

### Hugging Face LLM Course
**Link:** [huggingface.co/learn/llm-course/chapter1/1](https://huggingface.co/learn/llm-course/chapter1/1)

Covers the transformer architecture, tokenization, using the Hugging Face Transformers library, fine-tuning on custom datasets, deploying models, and evaluating LLMs. Written tutorials with real code examples.

Free.

Good for engineers who want to go beyond API calls and work directly with open-source models.

### Andrej Karpathy — Neural Networks: Zero to Hero
**Link:** [youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ)

Backpropagation from scratch, building an autograd engine, neural networks without libraries, a character-level language model, and a full GPT implementation from scratch. Karpathy writes every single line of code on camera and explains every decision.

Free on YouTube.

One of the best free resources in the field. If you want to genuinely understand how these systems work at the lowest level, start here.

## System Design

### ByteByteGo System Design Playlist
**Link:** [youtube.com/watch?v=dGAgxozNWFE&list=PLCRMIe5FDPsd0gVs500xeOewfySTsmEjf&index=6](https://www.youtube.com/watch?v=dGAgxozNWFE&list=PLCRMIe5FDPsd0gVs500xeOewfySTsmEjf&index=6)

Scalability, caching, Redis, message queues, load balancing, database design at scale, and walkthroughs of designing real systems. Short animated videos, most are 5–10 minutes and very dense.

Free on YouTube. ByteByteGo also has a paid newsletter and book (optional, not required).

Good for engineers preparing for system design interviews, or anyone building systems that need to handle real traffic.
