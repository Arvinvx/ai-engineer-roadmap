# Contributing

Thanks for wanting to help improve this. It's an open-source project and stays useful because people contribute when they find something better.

## What's Welcome

- Better or newer resources — if something has been updated or a better alternative exists, suggest it with a reason
- Broken links or outdated info — things change, especially in the AI space
- New project ideas — especially ones that solve specific real problems
- Clarity improvements — if an explanation is confusing or assumes too much, say so
- Missing topics — important concepts that aren't covered
- Translations — open an issue first to coordinate before starting

## What We Skip

- Promotional additions without clear educational value
- Resources where paid is the only option and no free alternative exists
- Additions that make the roadmap longer without making it more useful

## How to Contribute

**Option 1 — Open an issue (easiest)**

If you found a problem or want to suggest something, open an issue with:
- What the issue or suggestion is
- Why it should change
- A link to the resource if you're suggesting one

You don't need to edit any files. If the suggestion is good, someone will add it.

**Option 2 — Submit a pull request**

1. Fork the repo
2. Create a branch: `git checkout -b your-branch-name`
3. Make your changes
4. Commit clearly: `git commit -m "Add X resource to Stage 4"`
5. Push: `git push origin your-branch-name`
6. Open a PR against `main`

In the PR description, include what you changed, why, a link if relevant, and whether you've personally used the resource.

## Adding a Resource

When suggesting a learning resource, include:

| Field | Description |
|---|---|
| Name | Name of the resource |
| Link | Direct URL |
| What it covers | 2–3 sentences |
| Format | Video, interactive, written, book, course |
| Cost | Free, freemium, or paid |
| Why it belongs | What's missing from the roadmap that this fills |

Resources get added based on educational quality, not popularity.

## Code of Conduct

Be respectful. No spam or low-effort suggestions. Assume good faith.

## Maintainers

Community maintained. If you want to help maintain it long-term, open an issue and introduce yourself after a few meaningful contributions.
